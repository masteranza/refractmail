# Refract Mail

The website for Refract Mail, a native macOS app for Gmail:
<https://refractmail.com/>

- [`index.html`](index.html) — the homepage
- [`privacy/`](privacy/index.html) — the privacy policy
- [`terms/`](terms/index.html) — the terms of service

Plain HTML and one stylesheet, served by GitHub Pages from `main`. No
scripts, web fonts or analytics, so the pages make no third-party requests.

Questions, bug reports and beta access requests: [issues](https://github.com/masteranza/refractmail/issues).
